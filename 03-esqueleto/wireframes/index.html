Wireframes do fluxo de alertas

Telas que cobrem a tarefa prioritária completa: encontrar um alerta de alta severidade ainda aberto, consultar o ativo afetado e o horário do evento e voltar para a lista com os filtros preservados.

Dados fictícios de demonstração

Arquivo Tela Cobertura

03-detalhe-alerta.html Detalhe do alerta ALT-0001 RF03, RF08, RF10 — ativo, horário e retorno
04-estados.html Carregamento, erro, vazio e confirmação RF07 — estados de interface

Percursos possíveis nos wireframes

  1. Visão geral → lista filtrada → detalhe → volta para a lista com filtros.
  2. Lista → erro de consulta → "Tentar novamente".
  3. Lista → lista vazia → "Limpar filtros".
